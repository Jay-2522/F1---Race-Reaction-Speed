# F1 Race Start Reaction Time

🏎️ Think you've got F1-level reflexes? 👀 Prove it!

This web app tests how quick you are off the grid 🟢💨

## 🚦 How It Works

- Wait for the 5 red lights to light up 🔴🔴🔴🔴🔴
- Get ready... get set... GO when the green light flashes 🟢
- Tap or click as fast as you can
- Compete against bots with random reaction times 🤖
- Final scoreboard = flex time 😎

## 🧠 Features

- 🔁 Randomized green light timing (no cheating 👀)
- 🤖 AI opponents with realistic reflexes
- 🏆 Leaderboard with reaction times
- 📱 Mobile & Desktop friendly
- 🚫 Jump start = instant DQ (just like real F1)

## 📦 Local Development

```bash
# Clone the repository
git clone https://github.com/mxyxyz9/race-start-reaction-time.git
cd race-start-reaction-time

# Install dependencies
npm install

# Run development server
npm run dev
```

## 🎯 Game Rules

1. **Wait for the lights**: Don't jump the start!
2. **React quickly**: Click as soon as you see green
3. **Beat the bots**: Compare your time against AI drivers
4. **No false starts**: Jumping early results in disqualification

## 📊 Scoring

- **Perfect Start**: < 200ms (F1 Pro level)
- **Great Start**: 200-300ms (F2 level)
- **Good Start**: 300-400ms (F3 level)
- **Average**: 400-500ms (Amateur)
- **Needs Practice**: > 500ms
